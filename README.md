# Бот для правил беседы ВКонтакте

Бот читает события сообщества через Bots Long Poll. Он сравнивает текст сообщения со списком слов и отправляет напоминание только в настроенную беседу.

## Установка

Требуется Python 3.11 или новее. Выполните команды из папки проекта в PowerShell.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Настройка и запуск

Имена параметров перечислены в `.env.example`. Программа читает окружение. Укажите собственные значения в текущем сеансе PowerShell.

```powershell
$env:VK_ACCESS_TOKEN='<ваше значение>'
$env:VK_GROUP_ID='<ваше значение>'
$env:VK_CHAT_PEER_ID='<ваше значение>'
.\.venv\Scripts\python.exe main.py
```

Включите Bots Long Poll и событие новых сообщений в тестовом сообществе. Укажите ключ сообщества с правом на сообщения, его числовой `VK_GROUP_ID` и идентификатор тестовой беседы `VK_CHAT_PEER_ID`. Список слов в `VK_RULE_WORDS` задаётся через запятую.

Рабочие ключи, базы и файлы состояния предназначены для локального хранения. Проверяйте подключение в собственном тестовом чате или канале.
